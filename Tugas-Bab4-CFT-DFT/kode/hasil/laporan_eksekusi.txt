### soal05_infeasible
=== Soal 5: Analisis Jalur Tak Layak ===

1) Analisis simbolik (tanpa eksekusi)
   Syarat simpul B3 (cout "Proses A"):
     c1: x > 10
     c2: x < 5
   Gabungan: x > 10 DAN x < 5
   Interval c1 = (10, +inf), interval c2 = (-inf, 5)
   Irisan    = kosong (empty set)
   Kesimpulan: jalur B1->B2->B3->B4 TIDAK LAYAK (infeasible).

2) Pembuktian empiris (brute force)
   Rentang x yang disisir : [-1000000, 1000000]
   Jumlah x yang mencapai "Proses A" : 0
   Tidak ada input yang dapat mengeksekusi B3.

3) Jalur yang LAYAK pada CFG tersebut
   P1: B1->B2(true)->B3(false)->B4   (x > 10, x >= 5)
   P2: B1->B2(false)->B4             (x <= 10)
   P3: B1->B2(true)->B3(true)->...   (TIDAK LAYAK)

4) Implikasi pengujian
   - Jangan buang waktu mencari input untuk P3.
   - Dokumentasikan P3 sebagai infeasible beserta alasannya.
   - Perbaiki struktur kondisi bila memang ada maksud logika lain
     (mis. x > 10 && x < 5 kemungkinan salah tulis).

### soal08_aliran_data
=== Soal 8: Anomali Aliran Data ===

Jejak peristiwa data:
  [1] deklarasi  : int nilai;            (belum ada nilai)
  [2] definisi   : nilai = 70            (d1)
  [3] definisi   : nilai = 85            (d2, d1 ditimpa)
  [4] penggunaan : cout << nilai         (u1 membaca d2)

Keluaran program: 85

Analisis:
  - Nilai yang ditampilkan adalah 85 (definisi terakhir sebelum use).
  - Nilai 70 adalah dead assignment: didefinisikan lalu langsung
    ditimpa tanpa pernah dibaca -> anomali DDU (Definisi-Definisi-
    Penggunaan) / definisi tanpa penggunaan.
  - Pasangan def-use yang sah: (d2, u1). Pasangan (d1, u1) TIDAK ADA
    karena d1 sudah di-kill oleh d2.
  - Pada kode asli tanpa inisialisasi, bila d1 dan d2 dihapus maka u1
    menjadi use-before-def (nilai tak terdefinisi) -> bug.

### soal09_dua_kasus
=== Soal 9: Kriteria Cakupan Aliran Data ===

Kasus uji 1: harga = 100000
  d1: harga  = 100000
  d2: diskon = 0
  u1: p-use harga pada kondisi (harga > 50000) -> TRUE
  d3: diskon = 10 (d2 ditimpa)
  u2: c-use harga -> total = 100000 - 10 = 99990
  u3: c-use diskon (nilai 10)
  d4: total = 99990
  u4: c-use total -> 99990

Kasus uji 2: harga = 30000
  d1: harga  = 30000
  d2: diskon = 0
  u1: p-use harga pada kondisi (harga > 50000) -> FALSE
  u2: c-use harga -> total = 30000 - 0 = 30000
  u3: c-use diskon (nilai 0)
  d4: total = 30000
  u4: c-use total -> 30000

--- Rekap ---
Peristiwa tercakup : d1 d2 d3 d4 u1 u2 u3 u4 
Pasangan def-use  : d1->u1 d1->u2 d2->u3 d3->u3 d4->u4 

Cakupan All-Defs  : d1, d2, d3, d4 masing-masing mencapai use
Cakupan All-Uses  : 5 pasangan layak -> butuh 2 kasus uji
All-DU-Paths      : d1->u2 memiliki 2 jalur berbeda (true/false)
