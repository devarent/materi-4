2. VERIFIKASI STATEMENT & BRANCH COVERAGE (SOAL 3)
==============================================================================

Skenario: hanya nilai 80
  input   80 -> pernyataan ['S1', 'S2', 'S3'], cabang TRUE
  Statement coverage = 3/4 = 75%
  Branch coverage    = 1/2 = 50%

Skenario: nilai 80 dan 40
  input   80 -> pernyataan ['S1', 'S2', 'S3'], cabang TRUE
  input   40 -> pernyataan ['S1', 'S2', 'S4'], cabang FALSE
  Statement coverage = 4/4 = 100%
  Branch coverage    = 2/2 = 100%

Kesimpulan: satu kasus uji (80) menghasilkan 75% statement coverage
dan 50% branch coverage; tambahan kasus uji 40 mencapai 100%/100%.

3. VERIFIKASI JALUR LAYAK / TIDAK LAYAK
==============================================================================
Soal 5: syarat mencapai "Proses A" adalah x > 10 DAN x < 5
  Penyisiran x pada [-2000, 2000] : 0 nilai memenuhi
  Analisis interval: (10, +inf) interseksi (-inf, 5) = kosong
  Kesimpulan: jalur B1->B2->B3(true) TIDAK LAYAK (infeasible)
Soal 10a: kode asli dengan statusMahasiswa = 1 (konstan)
  TIDAK LAYAK : B1 -> B2 -> B3 -> B5 -> B7 -> B8
  TIDAK LAYAK : B1 -> B2 -> B3 -> B5 -> B6 -> B8
  TIDAK LAYAK : B1 -> B2 -> B3 -> B4 -> B5 -> B7 -> B8
  LAYAK      : B1 -> B2 -> B3 -> B4 -> B5 -> B6 -> B8
  Jumlah jalur sederhana = 4, layak = 1, tidak layak = 3
  V(G) = 3 tetapi jalur layak hanya 1.
  -> V(G) adalah batas ATAS, bukan jaminan jumlah jalur yang dapat diuji.

Soal 10b: setelah statusMahasiswa dijadikan input (refactoring)
  LAYAK      : B1 -> B2 -> B3 -> B5 -> B7 -> B8
  TIDAK LAYAK : B1 -> B2 -> B3 -> B5 -> B6 -> B8
  TIDAK LAYAK : B1 -> B2 -> B3 -> B4 -> B5 -> B7 -> B8
  LAYAK      : B1 -> B2 -> B3 -> B4 -> B5 -> B6 -> B8
  layak = 2, tidak layak = 2; dua kasus uji (status 1 dan 0) mencapai 100% branch coverage.

4. ANALISIS ALIRAN DATA: PASANGAN DU & ANOMALI
==============================================================================
Soal 8 - kode: int nilai; nilai = 70; nilai = 85; cout << nilai;
Jalur dianalisis : 1
Pasangan DU      : 1
  (B3 -> B4) var 'nilai' : 1 jalur unik
Anomali def-without-use (dead store):
  definisi nilai di B2 tidak pernah digunakan
  Kesimpulan: keluaran 85; definisi 70 adalah dead store (DDU).

Soal 9 contoh 1 - kode: harga/diskon dengan cabang if
Jalur dianalisis : 2
Pasangan DU      : 5
  (B1 -> B3) var 'harga' : 1 jalur unik
  (B1 -> B5) var 'harga' : 2 jalur unik
  (B2 -> B5) var 'diskon' : 1 jalur unik
  (B4 -> B5) var 'diskon' : 1 jalur unik
  (B5 -> B6) var 'total' : 1 jalur unik
  Kriteria (terpenuhi/total): {'All-Defs': (4, 4), 'All-Uses': (5, 5), 'All-DU-Paths': (6, 6)}
  Catatan: (d2 -> u3) hanya terpenuhi pada jalur FALSE,
           (d3 -> u3) hanya pada jalur TRUE -> All-Uses butuh 2 kasus uji.

Soal 10 - kode KRS (statusMahasiswa sebagai input)
Jalur dianalisis : 4
Pasangan DU      : 3
  (B1 -> B5) var 'sks' : 1 jalur unik
  (B2 -> B3) var 'statusMahasiswa' : 1 jalur unik
  (B4 -> B5) var 'sks' : 1 jalur unik
  Catatan: pada jalur mahasiswa aktif, definisi sks = 0 (B1)
           langsung ditimpa sks = 20 (B4) -> dead store lokal (DDU).
           statusMahasiswa hanya punya 1 definisi (B2), 1 p-use (B3).
